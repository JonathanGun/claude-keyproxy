# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep feedback about the work.

To report a problem, contact the maintainer, [@JonathanGun](https://github.com/JonathanGun), privately on GitHub. Reports are kept confidential.
